# Expense-Tracker

---

## Description

Created an **Expense Tracker** using React JS and to be honest, it was all well worth the effort!
Designed it from scratch using Vanilla CSS, which took longer than it would have with a UI library, but allowed me to control every aspect of the design.
To make the experience more intuitive and engaging, I added two data visualization tools to help users actually understand their expenses not just track them.

---

## Tech stack

`React JS`
`Vanilla CSS`
`Chart JS`
